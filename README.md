# Lab1_bajengo-lab
 This repository contains my solution for the road simulation python file.
 
 A Full Self Driving simulation of a Tesla driving from ALU Rwanda to the Kigali Convention Centre. The road is a Python list, and each item is a 100 m segment holding a sign: a speed limit, a zebra crossing, a bus, or plain road.

How to run:

bash
python road_simulation.py

Enter a driver name.
Use the road editor menu (add, insert, replace, show).
Choose 5. Start driving and open the link (e.g. http://127.0.0.1:8008).
Press Enter in the terminal to start the car.
